¿Dónde está Observer?

El sensor publica el cambio. Cada observador suscrito ejecuta su propia acción: actualizar la pantalla, comprobar alertas o guardar el historial.

FLUJO DE COMUNICACIÓN

¿Cómo funciona?

  1. 01
    Suscripción

    Los observadores se registran en el sensor.

  2. 02
    Cambio de estado

    El usuario modifica la temperatura simulada.

  3. 03
    Notificación

    El sensor comunica el nuevo valor a sus suscriptores activos.

  4. 04
    Respuesta independiente

    Cada observador ejecuta su propia lógica.

Demo académica: la temperatura se simula desde el navegador; no representa una medición física real.
CONCEPTO CLAVE

El sujeto no depende de las clases concretas

El sensor conoce el contrato de notificación, no las tareas particulares de cada observador. Puedes agregar nuevas reacciones sin modificar la lógica principal del sensor.

observer.js · idea simplificada
class Sensor {
  suscribir(observador) { ... }
  cancelar(observador) { ... }
  notificar(temperatura) {
    this.observadores.forEach(
      observador => observador.actualizar(temperatura)
    );
  }
}
